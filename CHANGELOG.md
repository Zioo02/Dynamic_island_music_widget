# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] – 2026-10-05

### Added
- Menu bar island with round artwork, "Title – Artist" and equalizer bars.
- Equalizer bars that follow the actual audio (low / mid / high bands) on macOS 14.2+, with a gentle idle animation as a fallback.
- Accent colour for the bars taken from the current artwork.
- Frosted glass background that adapts its height to the menu bar.
- Click panel styled after macOS "Now Playing": large artwork, title, artist and album, playback controls and a seekable progress bar.
- Clicking the artwork or title in the panel opens the player app.
- English and Polish interface, chosen from the system language.
- Install and uninstall scripts with launch at login.
